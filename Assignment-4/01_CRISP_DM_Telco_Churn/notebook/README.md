# Colab execution guide

1. Open CRISP_DM_Telco_Churn.ipynb in Google Colab.
2. Run the install cell.
3. Run the source cell with %run CRISP_DM_Telco_Churn.py.
4. Inspect the generated artifacts folder.
5. Reconcile the metrics in the report with artifacts/evaluation_metrics.json.

The source script is organized by all six CRISP-DM stages and uses an out-of-fold training threshold before final held-out evaluation.
