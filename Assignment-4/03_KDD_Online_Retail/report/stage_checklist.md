# KDD stage checklist

- [x] Selection: population, fields, period, discovery questions
- [x] Preprocessing: invalid records, cancellations, missing identifiers
- [x] Transformation: RFM and basket representations
- [x] Data mining: clustering and association rules
- [x] Interpretation: segment profiles and product-rule review
- [x] Evaluation: silhouette, support, confidence, lift, stability plan
- [x] Exported knowledge artifacts and operational handoff
