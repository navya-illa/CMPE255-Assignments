# Colab execution guide

1. Open KDD_Online_Retail.ipynb in Google Colab.
2. Run the install cell.
3. Run the source cell with %run KDD_Online_Retail.py.
4. Inspect the cluster-selection chart, segment profiles, and association rules.
5. Reconcile the report with artifacts/knowledge_summary.json.

The source script implements Selection, Preprocessing, Transformation, Data Mining, and Interpretation/Evaluation.
