# Principled Data Science with CRISP-DM, SEMMA, and KDD

This repository demonstrates three complete, methodology-driven data-science projects. Each project uses a different dataset and follows every stage of its assigned methodology.

## Projects

| Methodology | Dataset | Objective |
|---|---|---|
| CRISP-DM | IBM Telco Customer Churn | Predict churn and translate model results into retention actions |
| SEMMA | Bank Marketing | Predict whether a customer will subscribe to a term deposit |
| KDD | Online Retail | Discover customer segments and purchasing associations |

## AI-assisted review policy

GPT-5-level critique prompts are included for each stage. The prompts use an expert-reviewer persona to stress-test completeness, validity, leakage, evaluation, reproducibility, and communication. The critique logs distinguish between draft, review, revision, and verification. AI-generated code must still be executed and checked manually.
