# Colab execution guide

1. Open SEMMA_Bank_Marketing.ipynb in Google Colab.
2. Run the install cell.
3. Run the source cell with %run SEMMA_Bank_Marketing.py.
4. Confirm the duration leakage decision and inspect the assessment artifacts.
5. Reconcile the report with artifacts/evaluation_metrics.json.

The source script explicitly implements Sample, Explore, Modify, Model, and Assess.
