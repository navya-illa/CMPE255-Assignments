# FocusList — To-Do List Application

FocusList is a local-first To-Do List application created for Assignment 2 using VS Code and GitHub Copilot. It supports task creation, priorities, completion tracking, filtering, editing, deletion, clearing completed tasks, dark mode, and browser local storage.

## Run the application

No build tools are required.

1. Open this folder in VS Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Add and manage tasks.

## Run unit tests

Install Node.js if necessary, then run:

```bash
npm test
```


## Features demonstrated

- Add a task with low, medium, or high priority.
- Mark tasks complete and view progress.
- Filter all, active, or completed tasks.
- Edit and delete tasks.
- Clear all completed tasks.
- Toggle dark mode.
- Persist tasks with browser `localStorage`.
- Protect displayed task text with HTML escaping.
