# Part 2 — Five Data-Mining Problems

This directory contains five data-mining problems solved with the support of an AI coding assistant. Each problem has its own README, prompt record, requirements file, data, source code, notebook, reports, and exported artifacts.

## Problems

| Problem | Folder | Selected method |
|---|---|---|
| Clustering | [`1) clustering/`](1%29%20clustering/) | K-Means, k = 6 |
| Classification | [`2) classification/`](2%29%20classification/) | Logistic regression |
| Association mining | [`3) association_mining/`](3%29%20association_mining/) | Apriori |
| Regression | [`4) regression/`](4%29%20regression/) | Random forest |
| Anomaly detection | [`5) anomaly_detection/`](5%29%20anomaly_detection/) | Isolation Forest |

## Results summary

The five problems are separate analyses, so their metrics are not directly comparable. See [`SUMMARY.md`](reports/five-problem-summary.md) for the five-problem results and [`PROMPTS.md`](PROMPTS.md) for the prompt index.

## Shared evidence standard

Each problem includes a data audit, comparison methods, appropriate metrics, exported artifacts, reproducibility instructions, limitations, references, and an AI-assistance disclosure.
