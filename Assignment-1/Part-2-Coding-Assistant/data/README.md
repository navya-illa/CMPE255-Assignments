# Dataset setup

Download [`Mall_Customers.csv`](https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python) and place it in this directory:

```text
data/Mall_Customers.csv
```

Expected columns:

```text
CustomerID
Gender
Age
Annual Income (k$)
Spending Score (1-100)
```

The dataset is not redistributed in this repository. `CustomerID` is used only to retain row identity, while `Gender` is used only for descriptive auditing. Neither is included in the clustering feature matrix.
